# Current transparent logo

The user approved the audio information card, large magnifier and wireless earbuds design and explicitly required transparency. `AppIcon-master.svg` is the clean production master of this composition. PNGs and ICOs are deterministically exported by `../FluentCurrent/build-icons.cjs`. Alpha ranges from 0 to 255; no pale background tile is present.

The pale-background raster in `../Approvals/tile-icon-round-9/` records the approved visual direction; failed imagegen transparency outputs are not production inputs. New vector geometry preserves the selected identity without colored edge fragments. No Bluetooth graphical mark is used as the app logo. The existing in-app Bluetooth function glyph is deliberately preserved.
